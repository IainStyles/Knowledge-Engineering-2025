## Propositions as Symbols

Consider the following sentence:

> If I am going outside and it is not raining then I do not take a coat or an umbrella.

Note that this sentence alone is not an argument: it is a statement - a proposition, which can be be True or False. We can also see that it is a compound proposition, made up of four atomic propositions:

- It is raining
- I am going outside
- I take a coat
- I take an umbrella

Note that this is not the same as the `if-then` construct that we are familiar with in Python and other programming languages. In programming, this construction takes an action in response to some condition. In logic, material implication does not take any action, it is a binary logic operator that should be treated in the same way as conjuction and disjunction. Thus, the statement $R\land O \implies U$ is True except when $R\land O$ is False and $U$ is True.

The Truth table for Implication can seem somewhat counter intuitive. The table matches our intuition when $P$ is True. When $P$ is False, it reflects that we can say nothing about the conclusion. Logic does not provide us with tools that express the notion that something "might be True" so we take the *possibility* of something being True to be equivalent to that same thing being True.

Lets's think about this in terms of a concrete example. Let's define:

- $P$: "It is raining"  
- $Q$: "I get wet"

The implication $P\implies Q$ translates as "If it is raining then I get wet". If $P$ and $Q$ are both True, then the implication is clearly True. If $P$ is True and $Q$ is False ("If it is raining I don't get wet"), then the implication is clearly False. If $P$ is False and $Q$ is True, ("If it is not raining I get wet"), we define the implication to be True, but this is what known as a **vacuous truth**: if $P$ is False then nothing is implied about $Q$. A slightly clearer example of this is "If pigs could fly then hell would freeze over": pigs cannot fly and so we can know nothing about whether hell will or won't freeze. If you find this confusing, you are in good company: *remember the Truth Table*!
